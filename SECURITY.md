# Security

Misha is a portfolio demonstration that runs entirely on synthetic, client-side data. It
does not provide real authentication, persistence, file storage, or production access
control, and it should not be used to manage a real owner association.

Do not enter confidential, financial, identity, property, or resident information into
the public demo.

If you find a security issue in the code or deployed demo, please contact the repository
owner privately through their GitHub profile instead of opening a public issue.
